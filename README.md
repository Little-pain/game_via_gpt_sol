# Силицид — «Искра в Пустоте» · v0.5.0

Локальная браузерная 3D-стратегия на Three.js/WebGL. Версия 0.5.0 сохраняет кампанию главы I и добавляет играбельную главу II «Хор Безмолвных Орбит»: семь отдельных астероидов, разведку, колонии, истощаемые жилы, межастероидные партии, технологическое древо и финал Матриарха II. Игровая модель, Three.js и ресурсы поставляются локально; CDN, платный API и облако не нужны. Это браузерный проект, а не перенос на игровой движок.

## Запуск

Требуется Node.js 20+ для тестов и Python 3 для локального HTTP-сервера.

**Windows PowerShell:**

```powershell
py -m http.server 8000
```

**Linux/macOS:**

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Не запускайте `index.html` двойным щелчком: ES-модули и WebGL требуют HTTP-сервера.

Для полной проверки:

```bash
npm install
npx playwright install chromium
npm test
```

Playwright на Linux может потребовать системные Chromium-библиотеки: `sudo npx playwright install-deps chromium`.

## Управление

- Выберите карточку постройки, затем клетку поверхности; `Esc` или ПКМ отменяет размещение.
- В главе II выберите тело кнопкой в блоке «Архипелаг» или кликните по астероиду в сцене. Состав и запасы раскрываются сканером за 4 энергии.
- Зародыш колонии строится на разведанном теле и летит несколько секунд. Он несёт ограниченный стартовый набор, а не создаёт мгновенную колонию.
- Выберите отправителя, получателя и вид сырья в панели архипелага, откройте тракт и отправьте партию. В пути грузы имеют ETA, очередь, временную остановку фронтом и возобновление после ремонта.
- Выберите здание на сцене, чтобы увидеть состояние и настроить его частоту. Дальний аккорд главы II требует резонаторы 432/1200 Гц на разных телах и маршрут между ними.
- **W/A/S/D** — панорама; **Q/E** — вращение; средняя кнопка мыши или Shift+ЛКМ и перетаскивание — панорама; Alt+ЛКМ и перетаскивание меняет угол; колесо — масштаб.
- Пауза, скорость ×1/×2/×3, сохранение/загрузка и переключатель качества находятся в интерфейсе. Кнопка архива в главе II возвращает к сохранённой копии главы I; глава II сохраняется отдельно и доступна для продолжения.

## Реализовано и проверено

| Область | Фактическая реализация |
|---|---|
| Глава I | Исходная кампания и её логистика сохранены; полный автоматический проход на реальной модели/tick завершается финалом Тела II. |
| Переход | Доступен только после победы главы I. Часть ресурсов и изученных технологий переносится; полный снимок главы I хранится в архиве, отдельный ключ браузера позволяет вернуться к ней, не теряя главу II. |
| Архипелаг | Семь самостоятельных нерегулярных 3D-мешей: Материнский фрагмент и шесть тел. Для каждого тела — отдельная локальная сетка клеток и поверхность. |
| Разведка и строительство | Сканер раскрывает состав и точное конечное количество жил. Выбор активного тела, клетки, уклона, локальной связности и стоимости проверяется моделью; большие здания занимают несколько клеток. |
| Колонии и маршруты | Оплаченный зародыш физически летит и укореняется. Порты и зародыши служат концами трактов; партии забирают сырьё из локального запаса, летят по маршруту с ETA, ограничением размера и очередью. Прерванные фронтом грузы стоят, не исчезая; тракт можно восстановить. |
| Ресурсы и фабрика | Силикат, металл, осколки, гравитационные включения, эхо-минерал и компоненты хранятся на месте добычи/производства. Жилы конечны и уменьшаются в модели и на сцене. Сборщик потребляет локальные ресурсы с задержкой, создаёт видимые отдельные компоненты, которые поступают к Матриарху внутренним транспортом. |
| Технологии | 12 технологий главы II открывают разведку, колонизацию, тракты/грузовую пропускную способность, глубинный скол, селективную добычу, дальний аккорд, устойчивость к фронту, память гармоники, автономию и сборку ядра. Расходы исследования оплачиваются осколками и энергией. |
| Угроза и финал | Диссонансный фронт заранее предупреждает и временно закрывает маршруты, но не уничтожает уникальные жилы/грузы; есть обход через фазовое исследование и ручное восстановление. Для финала нужны дальний аккорд, Матриарх-камера, компоненты, включения, эхо-минерал и энергия. Сам ритуал идёт обычным тиком 60 игровых секунд и может быть сорван с возвратом материалов. |
| Сохранения | Формат v5 принимает старые v2/v3/v4 с безопасной миграцией. Сейв главы II включает тела, клетки, жилы, колонии, маршруты, очереди/партии, технологии и архив первой главы. |
| Графика | Локальный Three.js/WebGL, процедурные отдельные формы астероидов, mesh-постройки, сетка/маркеры жил, грузы, связи/траектории, освещение, динамические карты теней и частицы. Переключатель экономного качества снижает pixel ratio и отключает карты теней. |
| Локальный запуск | Без сервера игры, CDN, платных API, учётной записи или сетевого доступа после загрузки локальной папки. Интерфейс и подсказки — на русском. |

### Проверки в этой рабочей копии

Последний полный `npm test` после интеграции главы II завершился с кодом 0:

1. `node tests.js` — PASS: исходные механики главы I, ресурсы/логистика/исследование, старые сохранения и финал.
2. `node tests/full-chapter.js` — PASS: глава I **691,6 игровых секунд**, 29 действий, 642 доставленные единицы, 9 исследований; затем глава II через тот же `M.build`, `M.research`, `M.tick`, без выдачи ресурсов: **477,4 игровых секунды**, 7 тел, 455 доставленных единиц, 5 маршрутов, грузовая очередь/остановка/ремонт, конечные жилы, 9 исследований кампании главы II, отдельные проверки эффектов ещё трёх технологий и финал Матриарха II. Прохождение использует целевые действия, а не игровой ИИ/случайную стратегию.
3. `node tests/browser.js` — PASS в Chromium/WebGL: глава I UI, raycast-размещение, камера, частоты, логистика и сохранения; затем переходная кнопка, семь WebGL-мешей главы II, сетка, выбор тела, raycast-посадка зародыша, сейв/лоад рейса и низкое качество; **критических ошибок страницы/консоли нет**.

Скриншоты одинакового стандартного ракурса прилагаются: `screenshots/chapter-i-webgl.png` и `screenshots/chapter-ii-archipelago.png`.

## Ограничения и UX-риски

- Глава II проверена детерминированным тестовым маршрутом за 477,4 игровых секунд; это не полноценный пользовательский playtest. Скорость освоения и баланс на разных устройствах требуют проверки человеком. При ×1 это около восьми минут игрового времени; ускорение меняет время симуляции.
- Глобальная энергия пока является общим ресурсом кампании; в отличие от сырья, она не перевозится отдельными межастероидными партиями. Локальны запасы добычи и строительства; вычисление энергии распределённой сети пока абстрагировано.
- Тела — отдельные объёмные меши с поверхностной сеткой, но это не полноценная физическая симуляция сфер: склоны представлены дискретным порогом, а размещение ограничено небольшим набором индексированных клеток. Уровни детализации мешей и процедурные материалы простые.
- Грузы видимо идут по сегментам маршрута, однако полёт — модельная интерполяция, а не физика орбит/кораблей. Маршрутный фронт временно блокирует тракт, не разрушает его навсегда.
- Гравитационный запас и доступность разных колоний требуют внимания в UI; рекомендуемый порядок: сканирование → силикатная колония → локальная добыча/партии → металл/осколки/редкие тела → дальний аккорд → сборщик/финал. Новому игроку может понадобиться больше подсказок.
- Художественные модели процедурные и стилизованные, не авторские внешние ассеты; скриншоты показывают текущую геометрию, а не обещанный арт-план. Третья глава не реализована и не заявляется.
- Базовый Linux Playwright/WebGL прогон не гарантирует совместимость с каждой конфигурацией браузера/драйвера Windows. Для локальной диагностики откройте «Сигналы» и экспортируйте JSON-журнал.
