# Силицид — «Искра в Пустоте»

## Запуск

Нужен современный настольный браузер с WebGL2/WebGL. Открой проект в терминале:

```bash
python3 -m http.server 8000
```

Перейди на `http://localhost:8000`. Проект нельзя надёжно запускать двойным кликом по `index.html`: браузеры и встроенные статичные просмотровщики часто блокируют ES-модули/WebGL. Внешние CDN, API и сетевые ассеты игре не нужны: Three.js лежит локально в `vendor/`.

## Управление

- ЛКМ по постройке в списке, затем ЛКМ по астероиду — строить; призрак показывает поверхность/допустимость. `Esc` или ПКМ отменяет выбор.
- Колесо — масштаб; Shift+ЛКМ и перетаскивание или средняя кнопка — камера; `Q/E` — орбита; WASD — сдвиг; `⌂ К Матке` сбрасывает камеру.
- Клик по объекту показывает статус; `Delete` или кнопка демонтажа возвращает часть затрат.
- Пауза и скорость ×1/×2/×3 вверху. Сохранение и загрузка — через кнопки интерфейса.

## Что теперь действительно в симуляции

- **Настоящий 3D/WebGL:** нерегулярный процедурный меш астероида, перспективная камера с орбитой, объёмные кристаллы, источники света, тени, mesh-связи сети, ресурсные жилы, движущиеся носители и отдельные кристаллы-грузы. Three.js 0.186.1 локально; лицензия — `vendor/THREE-LICENSE.txt`.
- **Одна симуляция:** интерфейс и автотест вызывают один `SilModel.tick`. Модель обрабатывает время мелкими fixed steps; задержки кадра накапливаются и проигрываются, а не теряются. Есть ограничения catch-up и запись отброшенного времени в журнал.
- **Полная цепочка материалов:** экстрактор создаёт отдельный объект сырой руды; физически движущийся носитель доставляет его на Кристаллообогатитель или Узел памяти; фабрика перерабатывает его с затратой времени; готовый слиток/осколок/Ксенокварц снова становится отдельным грузом и летит к Матке. Только после приёмки Маткой содержимое входит в доступный запас. Очереди руды ограничивают добычу, поэтому видны реальные узкие места логистики.
- **Энергия, сеть, локальная температура, радиаторы, 432/1200 Гц, аккорд, 9 технологий, метеорные фронты, накопитель, щит, Кристаллизатор, Камера Слияния и Тело II.** Финальный ритуал — 45 секунд игрового времени; подготовленный улей проходит главу без выдачи тестом ресурсов.
- Начальный запас увеличен до 300 силикатов / 90 металла, чтобы можно было без энергоблокировки вырастить раннюю инфраструктуру, включая переработчик. Размеры и цены настраиваемы для баланса.

## Диагностика

Вкладка **Сигналы** теперь имеет экспорт полного журнала в JSON. Журнал записывает время реальное/игровое, переходы состояния, стройку, исследования, появление/погрузку/переработку/доставку грузов, паузу, задержки кадров, ошибки JavaScript, ошибки промисов и смену видимости вкладки. Буфер кольцевой, максимум 4 000 событий. Файл можно прислать для разбора; ключи и личные данные в журнал не записываются.

## Автотесты

Требуется Node.js 20+:

```bash
npm install
npx playwright install chromium
npm test
```

`npm test` запускает:

1. `tests.js` — расчёты сети, нулевой старт, рост, физический груз → производство → склад Матки, охлаждение, исследования, миграцию сохранений и достижимость ритуала.
2. `tests/full-chapter.js` — **полный первый проход с нуля**, настоящий план строительства и исследования, без бесплатной выдачи ресурсов/технологий. Используется та же функция `SilModel.tick` и фиксированный шаг 0.2 игрового секунды; метеорная случайность только зафиксирована для воспроизводимости теста.
3. `tests/browser.js` — Chromium/WebGL smoke-test: отсутствие остановки после первых секунд, создание/отмена через UI, настоящее размещение мышью, энергия, сеть, физические грузы и переработка, сохранение, пауза/продолжение и catch-up задержанного кадра. Консольные ошибки считаются провалом.

Для ускоренного внутрибраузерного прогона тестов служит только `?dev=1`; игроку это не требуется.

## Сохранения и известные границы

- Автосохранение и ручное сохранение в `localStorage`; формат v3. v2 безопасно мигрируется, старое состояние паузы при загрузке снимается, чтобы сохранение не оставляло мир замороженным.
- Один астероид и одна глава; следующей главы пока нет. Противники и боевая система отсутствуют.
- Физические партии ресурсов дискретны и видимы; это компактная логистическая модель, не симуляция каждого фрагмента руды. Геометрия, эффекты и карта процедурные.
